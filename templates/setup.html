F.R.I.D.A.Y. // FIRST-TIME CONFIGURATION

API KEY REQUIRED

This portable build needs your Google Gemini API key to come online. It will be saved to a local .env file next to the executable and remembered for future launches.

Privacy by default: your key stays in the local .env, screen sharing and memory learning are OFF, and only your typed prompt is sent to Google Gemini. Toggle both anytime from the app.
